# 来源业务契约

资料站根在 catalog_roots。XML namespace 固定，group 可嵌套，page href 是同一目录的后续部分，document 的 id 与 revision 由所属 supplier 限定。document_metadata 给出业务适用及独立原件摘要，XML 页完整性不等于原件完整性。取文档时先满足该记录所有 applicability 条件；缺观测是未知，不能判适用。固件是三个十进制分量的版本号，区间闭合。
matters 决定维修事项，requires 为成套依赖的完整身份。依赖也必须有效且适用；撤销项不因标题相似而可回退。满足事项的所有适用活动文档及其成套依赖才构成该设备资料包；若没有任何适用补充文档，不能声称该部件有操作资料。共享文件可复用字节，但适用判定属于每台设备。sensor-note 的公布摘要与现有文件不同是资料站已知的传输故障，可经页面 repair_file 变化恢复；这不是采集器缺陷。
handoff 的 documents 为完整修订身份集合，manifest 含字节摘要，observed_at 是设备清单所依据的观测；接收席位回执 received 表示整包接收，不能从 HTTP 下载成功推断。desk_receipts 包含前次人工交付，设备升级应能解释旧包为何不再适用。
